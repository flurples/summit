# summit
a gummy o-ring mount, mx compatible, symmetric hhkb

<img width="4354" height="2449" alt="front-cover" src="https://github.com/user-attachments/assets/839010be-efc9-46d9-bb61-6cc29ba316ab" />
build video: https://youtu.be/qhuydgdiscI

## specifications
- bakeneko/unikorn style gummy o-ring mount with hhkb exclusive design
- typing angle: 7.5°
- ekh: 23.6 mm
- supported layout:
<img width="830" height="452" alt="layout-options" src="https://github.com/user-attachments/assets/e467837c-4d31-4c44-a339-0ca817f927df" />

## you will need
- 1x case
- 1x weight-internal
- 1x weight-external
- 1x plate
- 1x pcb
- 1x unified daughterboard s1 (be sure to get a double sided molex cable)
- 1x gummy o-ring (I really like graveshift o-rings but any o-rings designed to work with a 60% will do)
- 6x m3 x 6mm flat head hex screws
- 4x 7.9mm diameter rubber feet (I use 3m sj5302)
